Creature Gatherer battle mock — playable 128×64 design spike · bead 2w8

Each design runs in its own window so they can sit side by side. All three use the same roster, generated data, production damage/move-use rules and the same seed if you pass one.

A · current — shipping 8-type dual menu

Baseline: the shipping menu, nothing tells you the matchup. Foe HP hidden like production.

B · trim — 4-type cycle + arrows + press-turn

▲/▼/·/× on every move row (final modifier incl. STAB), optional exact foe HP, optional press-turn extra action, type mode 4-single / 8-single / 8-dual.

C · duel — hidden pick among your creature's moves

Both pick hidden, reveal, and the 8-type wheel decides: win = full hit, lose = blocked + chip, neutral/mirror = trade. Creatures field their own equipped moves, so coverage differs per creature. AI read slider + AI READ tag.

8-type wheel (the whole matrix)

wind > earth > lightning > water > fire > plant > spirit > elder > wind — every type beats the next one clockwise and loses to the previous; all other pairs are neutral. No immunities, so every pick stays live.

keys in a window Arrows move cursor Z / Space A: confirm / advance X back to setup

Variant windows lock their design; number keys 1/2/3 do nothing there. Rerolling a seed in one window does not change the others. Fidelity: damage/HP/uses/speed/STAB ported from Damage.cpp, Type.hpp and MoveUses.hpp with stat stages at 0; statuses, effects, party/switch and animations are omitted.
